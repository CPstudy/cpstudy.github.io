# 디자인 시스템

UI 작업 시 반드시 이 스킬에 명시된 규칙을 따르도록 한다.

## 색상
|항목|라이트 모드|다크 모드|
|---|---|---|
|배경|#ffffff|#060607|
|글자|#060607|#ffffff|
|카드|#f2f3f5|#1a1a1a|
|보조|#e3e5e8|#333333|
|약간 흐린 글자|#4f5660|#9a9a9a|
|테두리|#e3e5e8|#333333|
|에러|#da373c|#ff6b6b|

## 버튼
- hover시 마우스는 hand 모양
- hover시 상태일 때 색상을 밝게 해야 함
- pressed 상태일 때 사이즈를 95%로 줄여야 함
- pressed 상태일 때 색상을 어둡게 해야 함
- disabled 상태일 때 투명도를 50%로 줄여야 함
