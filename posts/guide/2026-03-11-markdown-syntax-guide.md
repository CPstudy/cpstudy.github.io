## 마크다운이란?

마크다운(Markdown)은 텍스트 기반의 경량 마크업 언어입니다. 읽기 쉽고 쓰기 쉬운 문법으로 HTML로 변환할 수 있습니다.

---

## 1. 제목 (Headings)

```
# H1 — 가장 큰 제목
## H2 — 두 번째 제목
### H3 — 세 번째 제목
#### H4 — 네 번째 제목
##### H5 — 다섯 번째 제목
###### H6 — 가장 작은 제목
```

---

## 2. 텍스트 강조 (Emphasis)

| 문법 | 결과 |
|------|------|
| `**굵게**` | **굵게** |
| `*기울임*` | *기울임* |
| `~~취소선~~` | ~~취소선~~ |
| `**_굵고 기울임_**` | **_굵고 기울임_** |

---

## 3. 목록 (Lists)

### 순서 없는 목록

- 항목 1
- 항목 2
  - 중첩 항목 2-1
  - 중첩 항목 2-2
- 항목 3

### 순서 있는 목록

1. 첫 번째
2. 두 번째
   1. 중첩 2-1
   2. 중첩 2-2
3. 세 번째

---

## 4. 링크와 이미지 (Links & Images)

링크: `[표시 텍스트](URL)`

예시: [GitHub](https://github.com)

이미지: `![대체 텍스트](이미지 URL)`

---

## 5. 코드 (Code)

### 인라인 코드

문장 중간에 `const x = 1;` 처럼 코드를 삽입할 수 있습니다.

### 코드 블록

```javascript
// JavaScript 예시
const greet = (name) => {
  return `Hello, ${name}!`;
};

console.log(greet("World")); // Hello, World!
```

```python
# Python 예시
def greet(name: str) -> str:
    return f"Hello, {name}!"

print(greet("World"))  # Hello, World!
```

```bash
# Shell 예시
echo "Hello, World!"
npm install
git commit -m "feat: add new feature"
```

## 6. 인용문 (Blockquote)

> 이것은 인용문입니다.
>
> 여러 줄에 걸쳐 작성할 수 있습니다.
>
> > 중첩 인용문도 가능합니다.

---

## 7. 표 (Tables)

| 언어 | 패러다임 | 특징 |
|------|---------|------|
| JavaScript | 멀티 패러다임 | 웹의 표준 언어 |
| Python | 객체지향 + 함수형 | 읽기 쉬운 문법 |
| Rust | 시스템 프로그래밍 | 메모리 안전성 |
| Go | 절차형 | 간결함과 성능 |

---

## 8. 수평선 (Horizontal Rule)

세 개 이상의 `---`, `***`, `___` 로 구분선을 만듭니다.

---

## 9. 체크리스트 (Task List)

- [x] 마크다운 기본 문법 학습
- [x] 코드 블록 활용하기
- [ ] 블로그 포스트 꾸준히 작성하기
- [ ] 100개 포스트 달성하기

---

## 10. 이스케이프 (Escape)

특수 문자 앞에 `\`를 붙여 그대로 출력할 수 있습니다.

`\*별표\*` → \*별표\*

`\# 샵` → \# 샵

---

## 마치며

마크다운은 간결한 문법으로 구조적인 문서를 작성할 수 있어 개발자 블로그에 최적화된 형식입니다. 이 가이드를 참고해서 멋진 포스트를 작성해보세요!
